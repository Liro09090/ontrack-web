# OnTrack (varianta web)

Deschide **https://liro09090.github.io/ontrack-web/** în Safari pe iPhone, apoi **Partajează → Adaugă pe ecranul principal**.

Datele (mâncare, antrenamente, greutate) rămân doar pe telefonul fiecăruia. Imaginile exercițiilor: [Free Exercise DB](https://github.com/yuhonas/free-exercise-db), domeniu public.
